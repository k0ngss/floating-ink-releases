# 浮墨 · 透明阅读器

把本地小说显示成一层透明文字。支持框选其他窗口中的正文，取出字色并应用到小说。

**[下载 Windows 安装程序](https://github.com/k0ngss/floating-ink-releases/releases/latest/download/FloatingInk-Setup.exe)** · [查看版本和校验值](https://github.com/k0ngss/floating-ink-releases/releases/latest)

适用于 Windows 10 / 11，64 位。当前用户安装，无需管理员权限。

## 开始阅读

1. 下载并运行安装程序，完成后启动浮墨。
2. 点击“导入 TXT”，调整阅读窗大小和位置。
3. 点击“框选取字色”，框选一小段参考正文，选择候选色并应用。单击可取一个像素。
4. 点击“开始透明阅读”。背景、边框和控制台隐藏，仅保留文字，鼠标可操作下方软件。
5. 按 **Ctrl+Alt+Space** 唤回控制台；按 **Ctrl+Alt+左 / 右** 翻页。

右下角托盘图标也可唤出控制台。进度会自动保存。

## 更新与卸载

控制台中的“检查更新”可检查并下载新版本，完成 SHA-256 校验后询问是否运行安装包；也可以随时从此页面下载新版覆盖安装。

在 Windows“已安装的应用”中找到浮墨即可卸载。卸载保留小说文件和个人设置。

## 隐私和首版范围

阅读和取色离线完成，小说及截图不上传。仅手动检查更新时访问 GitHub。

取色按前景色分布估计，复杂图片背景请使用较小选区或单点取色。支持 TXT，暂不支持 EPUB/PDF。

首个试用版本未进行数字签名。请仅从此仓库下载，并可用 Releases 中的 SHA-256 校验文件确认完整性。

此公开仓库仅包含安装包、使用说明与更新信息；源码保存在独立私有仓库。
