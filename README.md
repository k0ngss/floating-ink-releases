# 浮墨 · 摸鱼模式

把本地小说显示成一层透明文字。简洁书架保留分类、搜索、改名和独立进度，点击「摸鱼模式」即可开始透明阅读。

**[下载最新 Windows 安装程序](https://github.com/k0ngss/floating-ink-releases/releases/latest/download/FloatingInk-Setup.exe)** · [版本和校验值](https://github.com/k0ngss/floating-ink-releases/releases/latest)

适用于 Windows 10/11，64 位。无需管理员权限。安装向导可选择目录、桌面快捷方式；升级会记住原目录。

## 开始阅读

1. 下载并运行安装程序，完成后启动浮墨。
2. 点击“导入 TXT”，或把 TXT 文件拖到书架；可批量导入。
3. 点击书名或“摸鱼模式”直接透明阅读，按 **Ctrl+Alt+左 / 右** 翻页。
4. 在“透明设置”中调整字号、字色、置顶和鼠标穿透；点击“调整透明窗”可拖动和缩放窗口。
5. 按 **Ctrl+Alt+Space** 切换摸鱼模式和调整窗口；按 **Ctrl+Alt+H** 隐藏或恢复文字。

托盘图标可恢复书架。每本书单独保存进度；点击小说旁的“···”可修改书名、分类和阅读状态，或移出书架。移出只删除书架记录，保留原 TXT。

## 安装、更新与卸载

0.1.1 起使用 NSIS 中文安装向导。默认安装到当前用户目录，也可选择其他位置；覆盖升级保留设置和进度。

启动时轻量检查版本，不自动下载，不弹窗打断阅读。在“透明设置 → 快捷键与更新”中查看新版说明，可选择“下载并安装”“稍后提醒”或“跳过此版本”。

下载显示进度并可取消，通过文件大小与 SHA-256 校验后，保存进度、关闭阅读器，再打开安装向导。也可下载新版手动覆盖安装。

Windows“已安装的应用”和开始菜单提供卸载入口。卸载保留小说及个人阅读设置。

## 隐私与说明

小说和取色截图不上传，阅读与取色可离线使用。版本检查、下载更新访问 GitHub。

支持 TXT，暂不支持 EPUB/PDF。复杂背景取色可缩小选区或使用单点取色。

试用版未进行数字签名。安装包内附 LiteView MIT 更新代码的版权声明。

公开仓库仅包含安装包、校验值、说明与更新清单；源码保存在独立私有仓库。
