# 浮墨 · 本地小说阅读

把本地 TXT 或文字 EPUB 显示成一层透明文字，也可框选屏幕区域，用纯色背景在原位阅读。简洁书架保留分类、搜索、改名和每本书独立的进度。

**[下载 Windows 安装程序 · 0.1.7](https://github.com/k0ngss/floating-ink-releases/releases/download/v0.1.7/FloatingInk-Setup-0.1.7.exe)** · [版本和校验值](https://github.com/k0ngss/floating-ink-releases/releases/tag/v0.1.7)

适用于 Windows 10/11，64 位。无需管理员权限。安装向导可选择目录、桌面快捷方式和开机自启动；自启动默认关闭，升级会记住原目录和已有选择。

## 开始阅读

1. 下载并运行安装程序，完成后启动浮墨。
2. 点击“导入小说”，或把 TXT / EPUB 文件拖到书架；可批量导入。
3. 点击书名或“开始阅读 / 继续阅读”，在预览中拖动、缩放阅读窗。调整边框贴合正文区域，确认前后保持文字位置，便于精确对齐。右键正文打开模式、字号和取色面板，按 **Esc** 收起面板。正文预览中按 **Enter** 开始阅读，按 **Esc** 返回书架。
4. 在“阅读设置 → 阅读外观”直接选择字体、字号、行距增量和字间距，调整即时生效、自动保存，并保留当前阅读位置。“排版…”还可精确设置段距、缩进与边距。设置与正文可以同时显示，关闭设置即可继续阅读。替换阅读可框选区域，同时提取背景色和字色。
5. 默认按 **Ctrl+Alt+左 / 右** 翻页，**Ctrl+Alt+Space** 恢复调整，**Ctrl+Alt+H** 隐藏或恢复文字。在“快捷键与更新”中可自定义单个按键、左右 Ctrl / Alt / Shift / Win、组合键或鼠标中键；单独修饰键在松开时确认。旧组合继续接受任一侧修饰键。启动发现冲突时会弹窗列出动作和组合，可立即修改或稍后处理。

托盘图标可恢复书架。每本书单独保存进度；点击小说旁的“···”可修改书名、分类和阅读状态、重新关联移动后的原书，或移出书架。移出只删除书架记录，保留原文件。

## 阅读工具与备份

阅读中右键正文打开“阅读导航”，可查看目录、书签和书内搜索，快速加书签或返回跳转前的位置。开启鼠标穿透时，可按 **Ctrl+Alt+G** 唤出导航。

“阅读设置 → 阅读外观 → 阅读工具”还提供目录识别规则、书签管理、字体排版、内容净化和阅读方案。净化只改变显示，不修改原书。阅读方案可保存排版、颜色、模式和窗口位置。

“阅读设置 → 快捷键与更新 → 备份与恢复”可导出书架、进度、书签、方案、规则与设置，也可带上原书。恢复会完整替换现有配置，确认前请另存当前备份；嵌入原书写入新目录，不覆盖原始小说。未带上的原书可在恢复后重新关联。嵌入原书每本最多 64 MiB，整包数据最多 256 MiB；更大的原书可选择只备份数据。

## 安装、更新与卸载

0.1.1 起使用 NSIS 中文安装向导。默认安装到当前用户目录，也可选择其他位置；覆盖升级保留设置和进度。

开机自启动默认关闭，可在安装向导组件页勾选，或在“阅读设置 → 窗口行为”切换。开启后在当前用户登录 Windows 时打开书架；升级保留已有选择，卸载清理本安装目录的启动项。此选项不随阅读方案或备份恢复而启用。

启动时轻量检查版本，不自动下载，不弹窗打断阅读。在“阅读设置 → 快捷键与更新”中查看新版说明，可选择“下载并安装”“稍后提醒”或“跳过此版本”。

下载显示进度并可取消，通过文件大小与 SHA-256 校验后，保存进度、关闭阅读器，再打开安装向导。也可下载新版手动覆盖安装。

Windows“已安装的应用”和开始菜单提供卸载入口。卸载保留小说及个人阅读设置。

## 隐私与说明

小说和取色截图不上传，阅读与取色可离线使用。版本检查、下载更新访问 GitHub。

支持 UTF-8、GB18030/GBK、UTF-16 TXT 和 EPUB2/3 可重排文字；EPUB 图片、复杂 CSS 和音视频降级，不支持 DRM、固定版式、PDF、在线书源及云同步。EPUB 容器最多 512 MiB，单资源正文最多 64 MiB，累计最多 256 MiB。复杂背景取色可缩小选区或使用单点取色。

试用版未进行数字签名。完整桌面端到端、混合 DPI/多屏、取色焦点、系统快捷键、重新关联人工操作和睡眠唤醒仍有待补验项。安装包内附 LiteView 与 miniz 的 MIT 版权声明。

公开仓库仅包含安装包、校验值、说明与更新清单；源码保存在独立私有仓库。
